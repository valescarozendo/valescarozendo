# Olá, eu sou a Valesca 👋🏾

**Desenvolvedora Back-End & Engenharia de Dados**

Meu trabalho é desenhar a infraestrutura que faz a informação rodar: construo pipelines (ETL), automatizo a limpeza de dados com Python e integro modelos de Inteligência Artificial para gerar análises técnicas e relatórios estruturados.

Tenho foco em entregar código limpo, testado e com arquitetura orientada a objetos, unindo o rigor metodológico da pesquisa acadêmica com lógicas de negócio sólidas para resolver problemas reais.
